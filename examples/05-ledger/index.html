ledger

Go reaches out to the browser rather than only being called by it. The balance lives in localStorage, and Go reads and writes it through two methods it declared for itself. Reload the page: it is still there.

Add(note string, amount int) Entry

What this example is showing

  • r.Import(&ledger.Saved, bind.At("localStorage")) — a Go variable of interface type, filled from an object the browser already has. Its two methods are checked while the bindings start, so a browser without storage fails the boot with a message rather than a nil interface at the first click.
  • ID int64 `crystalline:"bigint"` — entries are numbered from 9007199254740993, one past where a JavaScript number stops counting exactly. The field arrives as a bigint, and the number below is the one Go has. Without the tag it would read back one lower.
  • Note string `crystalline:"name=description"` — an explicit name, which wins over the naming convention.
  • -case camel — this is the one example generated that way, so the surface is ledger.add rather than ledger.Add. It is not optional here: an import looks for the name its own surface uses, and the browser's storage API is spelled the JavaScript way.
